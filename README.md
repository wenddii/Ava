# Ava's Glow Studio – Beauty Salon Website

A modern, responsive website developed for Ava's Glow Studio, a beauty salon based in Bole, Addis Ababa, Ethiopia.

## Overview

Ava's Glow Studio is a business website designed to strengthen the salon's online presence and make it easier for potential customers to discover its services, explore its work, and get in touch.

The website provides customers with essential business information in one place, helping the salon establish credibility and reach a wider audience, including local and international customers searching online.

## Key Features

- **Service Showcase:** Display the salon's beauty services and offerings.
- **Business Information:** Present salon location, operating hours, and contact details.
- **Visual Gallery:** Showcase the salon's work through images.
- **Contact Integration:** Make it easier for potential customers to contact the salon.
- **Google Maps Integration:** Help customers locate the salon and get directions.
- **Responsive Design:** Optimized for desktop and mobile devices.
- **Online Discoverability:** Structured website content designed to support search engine visibility.

## Technology Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_DIRECTORY
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

**Windows**
```bash
venv\Scripts\activate
```

**Linux/macOS**
```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure environment variables

Create a `.env` file and configure the required Django settings.

### 6. Run migrations

```bash
python manage.py migrate
```

### 7. Start the development server

```bash
python manage.py runserver
```

Visit `http://127.0.0.1:8000/` to access the website locally.
